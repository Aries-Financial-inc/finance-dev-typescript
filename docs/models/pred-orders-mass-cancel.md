# PredOrdersMassCancel

A mass cancel request and whether the venue accepted it. It does not list the orders canceled: each arrives as an order update.

## Example Usage

```typescript
import { PredOrdersMassCancel } from "@ariesdotcom/finance-dev/models";

let value: PredOrdersMassCancel = {};
```
