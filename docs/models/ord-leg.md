# OrdLeg

One option leg inside a single-leg or multi-leg order. Use this only for option orders; omit `legs` for normal stock orders.

## Example Usage

```typescript
import { OrdLeg } from "@ariesdotcom/finance-dev/models";

let value: OrdLeg = {
  maturity: new Date("2025-01-17"),
  positionEffect: "OPEN",
  putCall: "CALL",
  ratioQty: "1",
  securityType: "CS",
  side: "BUY",
  strikePrice: "150.00",
  symbol: "AAPL",
};
```
