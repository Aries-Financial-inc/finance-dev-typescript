# TradeOrderLegV2

Option leg on a v2 order (`order.Leg`). Multi-leg orders carry per-leg `avgPrice`; order-level `avgPrice` is zero when `legs` is non-empty.

## Example Usage

```typescript
import { TradeOrderLegV2 } from "finance-dev/models";

let value: TradeOrderLegV2 = {
  maturity: "<value>",
  positionEffect: "OPEN",
  putCall: "PUT",
  ratioQty: "<value>",
  securityType: "EQUITY",
  side: "BUY",
  strikePrice: "<value>",
  symbol: "<value>",
};
```
