# Contract

The contract's event, label, question and lifecycle. `null` when the event catalogue does not know `symbol`, or cannot be read; it never fails the request.

## Example Usage

```typescript
import { Contract } from "@ariesdotcom/finance-dev/models";

let value: Contract = {
  description: "Shelley Moore Capito",
  eventDisplayName: "West Virginia Senate General Election November 3 2026",
  eventId: "AXXWV_110326",
  question:
    "Will Shelley Moore Capito win the West Virginia general election for US Senate in 2026?",
  settlementValue: "1",
  state: "DELETED",
};
```
