# PredMdBaseEventHit

One base event with at least one matching contract. The index carries no display name; read it through /base-events/{baseEventId}. With sortBy=openInterest, ranked by its total open interest.

## Example Usage

```typescript
import { PredMdBaseEventHit } from "@ariesdotcom/finance-dev/models";

let value: PredMdBaseEventHit = {
  baseEventId: "<id>",
  contracts: [],
  contractsFound: 332757,
  openInterest: 2514201,
};
```
