# OrdResponse

Response returned after submitting an order request. Treat it as acknowledgement and continue monitoring order status until final fill, cancel, or rejection.

## Example Usage

```typescript
import { OrdResponse } from "@ariesdotcom/finance-dev/models";

let value: OrdResponse = {
  avgPrice: "0",
  clOrdId: "ORDER-20260115-001",
  cumQty: "0",
  leavesQty: "10",
  ordRejReason: "",
  qty: "10",
  side: "BUY",
  status: "NEW",
  success: true,
  symbol: "AAPL",
  text: "Order accepted",
  transactTime: new Date("2026-01-15T14:30:05Z"),
};
```
