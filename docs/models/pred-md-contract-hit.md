# PredMdContractHit

One matching contract, with its event's and base event's text flattened in. The index trails the catalogue by seconds; read the contract through /events/{eventId}/contracts when it must be current.

## Example Usage

```typescript
import { PredMdContractHit } from "@ariesdotcom/finance-dev/models";
import { Decimal } from "@ariesdotcom/finance-dev/types";

let value: PredMdContractHit = {
  baseEventId: "<id>",
  eventId: "<id>",
  state: "ACTIVE",
  symbol: "UNR_0822_3.5",
  symbolSubTypes: [],
  tickSize: new Decimal("0.01"),
  timeSpecifier: "2022.08",
  tradable: false,
};
```
