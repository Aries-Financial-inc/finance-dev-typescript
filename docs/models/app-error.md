# AppError

Structured application error returned inside an `ErrorEnvelope`.

## Example Usage

```typescript
import { AppError } from "@ariesdotcom/finance-dev/models";

let value: AppError = {
  code: "SYMBOL_REQUIRED",
  message: "string",
  type: "AUTHORIZATION",
};
```
