# OptionPreviousDayResponse

Previous trading session OHLC bar for an option contract.

## Example Usage

```typescript
import { OptionPreviousDayResponse } from "@ariesdotcom/finance-dev/models";

let value: OptionPreviousDayResponse = {
  close: 6508.35,
  high: 7553.03,
  low: 2865.21,
  open: 2459.63,
  ticker: "<value>",
  volume: 6842.51,
};
```
