# SearchSymbolResponseItem

One symbol search result. Use it to let users choose the exact instrument before fetching quotes, research data, or placing orders.

## Example Usage

```typescript
import { SearchSymbolResponseItem } from "finance-dev/models";

let value: SearchSymbolResponseItem = {
  type: "stock",
};
```
