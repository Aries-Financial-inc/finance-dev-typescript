# QuoteValues

Market quote values for a symbol. Use bid/ask for trading decisions and last price for display context.

## Example Usage

```typescript
import { QuoteValues } from "@ariesdotcom/finance-dev/models";

let value: QuoteValues = {};
```

## Fields

| ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `ask`                                                                                                                                      | *number*                                                                                                                                   | :heavy_minus_sign:                                                                                                                         | Lowest price sellers are currently willing to accept. Buyers usually compare their limit price to the ask.                                 |
| `bid`                                                                                                                                      | *number*                                                                                                                                   | :heavy_minus_sign:                                                                                                                         | Highest price buyers are currently offering. Sellers usually compare their limit price to the bid.                                         |

Use this for quote tiles and daily move displays.                                             |
