# EtbSearchResponse

Borrowability answers keyed by normalized (uppercase) symbol.

## Example Usage

```typescript
import { EtbSearchResponse } from "@ariesdotcom/finance-dev/models";

let value: EtbSearchResponse = {
  results: {
    "AAPL": true,
    "GME": false,
    "MSFT": true,
  },
};
```
