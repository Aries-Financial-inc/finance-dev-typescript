# SymbolDetails

Compact symbol summary returned by top movers and activity endpoints. Use it for market lists such as gainers, losers, and most active.

## Example Usage

```typescript
import { SymbolDetails } from "finance-dev/models";

let value: SymbolDetails = {
  change: 1.25,
  changePercent: 0.72,
  isETF: false,
  lastPrice: 175.43,
  logoUrl: "https://cdn.example.com/logos/AAPL.png",
  previousClose: 174.18,
  sector: "Technology",
  sicCode: "3571",
  symbol: "AAPL",
  timestamp: 1736956800,
  type: "stock",
  volume: 52000000,
};
```
