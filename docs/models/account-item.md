# AccountItem

User account item returned by GET /v2/users/me/accounts. Use `trading_account_id` as the `tradingAccountId` in order API requests. Account type and class are empty when broker metadata is unavailable (e.g. simulation accounts).

## Example Usage

```typescript
import { AccountItem } from "finance-dev/models";

let value: AccountItem = {
  accountClass: "<value>",
  accountType: "<value>",
  brokerAccountId: "3AF05000",
  isSim: true,
  status: "PENDING_CLOSE",
  tradingAccountId: "3AF05000",
};
```
