# News

## Overview

### Available Operations

* [getNews](#getnews) - Get Market News
* [getSentiment](#getsentiment) - Get News Sentiment
* [getById](#getbyid) - Get News by ID

## getNews

Retrieve real-time market news articles and press releases. Returns combined results from both news and press releases, sorted by timestamp (newest first). Default returns news for SPY if no symbols are specified.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getNews" method="get" path="/v1/news" example="default" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: process.env["PETSTORE_CLIENT_ID"] ?? "",
    clientSecret: process.env["PETSTORE_CLIENT_SECRET"] ?? "",
  },
});

async function run() {
  const result = await financeDev.news.getNews({
    symbols: "AAPL,GOOGL,MSFT",
    topics: "earnings,guidance",
  });

  console.log(result);
}

run();
```

## getById

Retrieve a specific news article or press release by its unique ID. Returns detailed information about a single news item. The ID must be numeric and newsType must be either 'news' or 'press_release'.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getNewsById" method="get" path="/v1/news/{id}" example="default" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: process.env["PETSTORE_CLIENT_ID"] ?? "",
    clientSecret: process.env["PETSTORE_CLIENT_SECRET"] ?? "",
  },
});

async function run() {
  const result = await financeDev.news.getById({
    id: "123456",
    newsType: "news",
  });

  console.log(result);
}

run();
```
