## getBar

Retrieve OHLC (Open, High, Low, Close) bar data for indices across various timeframes for technical analysis.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getIndexBar" method="get" path="/v1/indices/bar" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.indices.getBar({
    identifier: "SPX.IND_CBOM",
    endTime: "12/22/2025 10:30 am",
    precision: "Minutes",
    period: 1,
  });

  console.log(result);
}

run();
```

import { FinanceDevCore } from "finance-dev/core.js";
