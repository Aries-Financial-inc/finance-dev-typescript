## getEarnings

Retrieve historical earnings surprises comparing actual reported earnings to analyst estimates with surprise percentages.

If `limit` cannot be parsed as a signed 64-bit integer, returns 400 Bad Request with error code `INVALID_PARAMETER` and message `invalid limit parameter`.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getEarningsSurprises" method="get" path="/v1/stock/earnings" example="default" -->
```typescript
import { FinanceDev } from "@ariesdotcom/finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.stockEstimates.getEarnings({
    symbol: "AAPL",
  });

  console.log(result);
}

run();
```
