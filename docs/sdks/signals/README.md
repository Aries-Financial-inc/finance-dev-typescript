# Signals

## Overview

### Available Operations

* [getBullBear](#getbullbear) - Get Bull & Bear Analysis

## getBullBear

Retrieve bullish and bearish investment cases including fundamental arguments, technical signals, and analyst opinions for balanced perspective.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getBullBearAnalysis" method="get" path="/v1/signals/bull-bear" example="success" -->
```typescript
import { FinanceDev } from "@ariesdotcom/finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.signals.getBullBear({
    symbols: "AAPL,MSFT",
  });

  for await (const page of result) {
    console.log(page);
  }
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { FinanceDevCore } from "@ariesdotcom/finance-dev/core.js";
import { signalsGetBullBear } from "@ariesdotcom/finance-dev/funcs/signals-get-bull-bear.js";

// Use `FinanceDevCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const financeDev = new FinanceDevCore({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const res = await signalsGetBullBear(financeDev, {
    symbols: "AAPL,MSFT",
  });
  if (res.ok) {
    const { value: result } = res;
    for await (const page of result) {
    console.log(page);
  }
  } else {
    console.log("signalsGetBullBear failed:", res.error);
  }
}

run();
```
