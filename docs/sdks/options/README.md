## getActivity

Retrieve unusual options activity including large block trades, high volume contracts, and significant changes in open interest.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getOptionsActivity" method="get" path="/v1/options/activity" example="success" -->
```typescript

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.options.getActivity();

  for await (const page of result) {
    console.log(page);
  }
}

run();
```

## getChainSnapshot

    underlyingAsset: "AAPL",
