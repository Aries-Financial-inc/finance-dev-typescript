# Logos

## Overview

### Available Operations

* [search](#search) - Search Company Logos

## search

Search for company logos and brand assets by ticker symbol or company name for use in financial applications and dashboards.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="searchLogos" method="get" path="/v1/logos/search" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: process.env["PETSTORE_CLIENT_ID"] ?? "",
    clientSecret: process.env["PETSTORE_CLIENT_SECRET"] ?? "",
  },
});

async function run() {
  const result = await financeDev.logos.search({
    searchKeys: "AAPL,MSFT",
    searchKeysType: "symbol",
    fields: "logo_light,logo_dark,mark_light,mark_dark",
  });

  console.log(result);
}

run();
```

## sync

Synchronize and retrieve the latest company logos ensuring brand assets are up-to-date across all platforms.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="syncLogos" method="get" path="/v1/logos/sync" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: process.env["PETSTORE_CLIENT_ID"] ?? "",
    clientSecret: process.env["PETSTORE_CLIENT_SECRET"] ?? "",
  },
});

async function run() {
  const result = await financeDev.logos.sync({
    fields: "logo_light,logo_dark,mark_light,mark_dark",
    page: 0,
    pageSize: 10,
  });

  for await (const page of result) {
    console.log(page);
  }
}

run();
```
