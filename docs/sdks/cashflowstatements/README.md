# Financials.CashFlowStatements

## Overview

### Available Operations

* [get](#get) - Get Cash Flow Statements

## get

Retrieve SEC cash flow statement rows per filing period. Filter by CIK, tickers, filing or period dates, fiscal year/quarter, timeframe, and pagination. Same query shape as income statements.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getCashFlowStatements" method="get" path="/v1/financials/cash-flow-statements" example="default" -->
```typescript
import { FinanceDev } from "@ariesdotcom/finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.financials.cashFlowStatements.get();

  for await (const page of result) {
    console.log(page);
  }
}

run();
```
