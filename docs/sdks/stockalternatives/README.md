## getLobbying

Retrieve lobbying data for a symbol within a date range.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getLobbying" method="get" path="/v1/stock/lobbying" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.stockAlternatives.getLobbying({
    symbol: "AAPL",
    from: new Date("2024-01-01"),
    to: new Date("2024-12-31"),
  });

  console.log(result);
}

run();
```
