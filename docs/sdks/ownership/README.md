## getInstitutional

Retrieve institutional ownership data showing the percentage of shares held by institutional investors and changes over time.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getInstitutionalOwnership" method="get" path="/v1/institutional/ownership" example="default" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.ownership.getInstitutional({
    cusip: "023135106",
    from: new Date("2024-01-01"),
    to: new Date("2024-12-31"),
    symbol: "TSLA",
  });

  console.log(result);
}

run();
```
