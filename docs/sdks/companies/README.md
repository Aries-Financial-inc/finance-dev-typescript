# Companies

## Overview

### Available Operations

* [getPeers](#getpeers) - Get Company Peers

## getPeers

Retrieve a list of peer companies within the same industry or sector that are comparable in size and business model.

Returns 404 Not Found with error code `NOT_FOUND` when no peers are available for the specified symbol.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getCompanyPeers" method="get" path="/v1/company/peers" example="default" -->
```typescript
import { FinanceDev } from "@ariesdotcom/finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const result = await financeDev.companies.getPeers({
    symbol: "AAPL",
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { FinanceDevCore } from "@ariesdotcom/finance-dev/core.js";
import { companiesGetPeers } from "@ariesdotcom/finance-dev/funcs/companies-get-peers.js";

// Use `FinanceDevCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const financeDev = new FinanceDevCore({
  security: {
    clientID: "<YOUR_CLIENT_ID_HERE>",
    clientSecret: "<YOUR_CLIENT_SECRET_HERE>",
  },
});

async function run() {
  const res = await companiesGetPeers(financeDev, {
    symbol: "AAPL",
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("companiesGetPeers failed:", res.error);
  }
}

run();
```
