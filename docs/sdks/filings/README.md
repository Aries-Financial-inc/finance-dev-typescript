## getSec

Retrieve Securities and Exchange Commission (SEC) filings including 10-K annual reports, 10-Q quarterly reports, 8-K current reports, and proxy statements.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getSecFilings" method="get" path="/v1/filings/sec" example="default" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: process.env["PETSTORE_CLIENT_ID"] ?? "",
    clientSecret: process.env["PETSTORE_CLIENT_SECRET"] ?? "",
  },
});

async function run() {
  const result = await financeDev.filings.getSec({
    symbol: "AAPL",
    form: "10-K",
  });

  console.log(result);
}

run();
```

## getSimilarityIndex

Retrieve similarity scores comparing current SEC filings to previous filings to identify significant changes in disclosures and risk factors. Provide either `symbol` or `cik`: `symbol` is required when `cik` is omitted, and `cik` is required when `symbol` is omitted. `freq` is optional.

At least one of symbol or cik is required; both are accepted.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getFilingsSimilarityIndex" method="get" path="/v1/filings/similarity-index" example="default" -->
```typescript
import { FinanceDev } from "finance-dev";

const financeDev = new FinanceDev({
  security: {
    clientID: process.env["PETSTORE_CLIENT_ID"] ?? "",
    clientSecret: process.env["PETSTORE_CLIENT_SECRET"] ?? "",
  },
});

async function run() {
  const result = await financeDev.filings.getSimilarityIndex({
    symbol: "MSFT",
    freq: "quarterly",
  });

  console.log(result);
}

run();
```
